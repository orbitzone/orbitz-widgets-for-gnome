# Origem, créditos e licenças

Orbitz Widgets for GNOME é desenvolvido e mantido por **Felipe Santiago / orbitzone**, no [repositório Orbitz](https://github.com/orbitzone/orbitz-widgets-for-gnome). Essa atribuição identifica o projeto e suas modificações; não substitui a autoria dos componentes anteriores.

A logo atual `extension/media/orbitz-logo.svg` é um desenho vetorial original criado para o projeto Orbitz, com anel, órbita e satélite; não deriva do relógio visual da base. O logo legado permanece preservado entre os recursos históricos e atribuído abaixo, sem ser a marca principal.

A extensão teve como ponto de partida Desktop Clock / azclock v7, de Andrew Zaech. O código herdado e suas atribuições permanecem reconhecidos abaixo. Orbitz possui identidade, escopo e desenvolvimento próprios; não é uma versão oficial do projeto de origem. Arquivos de licença originais, bibliotecas vendorizadas, traduções e recursos mantêm seus avisos/termos. Esta mudança de identidade não muda a licença do código herdado nem a autoria desses componentes.


Desktop Clock / azclock: **Andrew Zaech**. Personalizações e widgets Orbitz: **orbitzone / Orbitz**. A extensão inclui o texto da licença GNU GPL v3 em seu arquivo `LICENSE`; bibliotecas, ferramentas e recursos visuais mantêm suas próprias licenças. A CLI da Ookla possui termos separados.
