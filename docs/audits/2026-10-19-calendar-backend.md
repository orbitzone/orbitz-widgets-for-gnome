# CAL-01 — backend estável, revisão de credenciais pendente

19/10/2026. Novos `calendar_accounts`, `google_oauth`, `google_client`, `calendly_client`, `calendar_http`, `calendar_api_events`; ampliados `credential_vault` e `store` (tarefas importadas explicitamente). iCloud/ICS e dados locais preservados; ferramentas/instalação não alteradas.

Contrato frontend: `calendar_accounts.connect_google(config_path,label,cancel_event=...,open_browser=...)`, `connect_calendly(token,label,cancel_event=...)`, `events(account,calendar,month,cancel_event=...)`, `disconnect(account)`. Google usa navegador, loopback IPv4/porta aleatória, state/PKCE S256; grant/configuração sensível no Secret Service separado, access token só RAM. Refresh serializado mantém token omitido/rotacionado; cancelamento desfaz conexão/cofre. URLs de API fixas, redirects recusados, paginação limitada, erros sem corpo/segredos; respostas incompletas não substituem cache. Eventos normalizados tratam cancelamento/recorrência/fuso. Descrições HTML/links de reunião não são persistidos pelos clientes novos.

Verificação: `test_calendar_providers.py`: **19 aprovados, 2 skips ambientais**; `test_planner_backend.py`: **8/8**; nove sintaxes. Testes cobrem isolamento de segredos, lifecycle, refresh concorrente, scopes, paginação/host, handlers reais em memória, importação sem mudar horas. Os dois cenários de socket real mantêm expectativas, mas o sandbox retorna `PermissionError: socket Operation not permitted`; executar o mesmo teste fora do sandbox. Nenhum login/cofre/API de conta real testado.

Dependências externas: JSON Desktop real do usuário, Calendar API/consentimento habilitados e Secret Service; PAT Calendly privado com `users:read`/`scheduled_events:read` (permissões insuficientes produzem erro explícito). PAT público/distribuído exigiria OAuth futuro. Revisão focada antes de aplicar. Sobre antigo: frontend confirmou fonte/instalação Orbitz; causa janela/cache não comprovada, nenhuma correção especulativa em launcher/updater.

Fontes oficiais consultadas: [Google Desktop/PKCE](https://developers.google.com/identity/protocols/oauth2/native-app), [CalendarList](https://developers.google.com/workspace/calendar/api/v3/reference/calendarList/list), [Events](https://developers.google.com/workspace/calendar/api/v3/reference/events/list), [Calendly scopes](https://developer.calendly.com/docs/authentication/scopes), [PAT privado](https://developer.calendly.com/docs/authentication/how-to-authenticate-with-personal-access-tokens), [paginação/eventos](https://developer.calendly.com/api-docs/calendly-api/scheduled-events/list-scheduled-events).
